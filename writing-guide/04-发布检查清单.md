# 04 发布检查清单

> 写作参考（本地），不会渲染到站点。

## 每篇文档完成时

- [ ] `npm run start` 本地预览，确认渲染效果符合预期
- [ ] 站内链接使用**相对路径**，且目标文档存在
- [ ] 图片已放入 `static/img/` 且路径正确
- [ ] 首次使用的组件（Tabs 等）已确认语法正确
- [ ] 同步完成英文翻译（`i18n/en/.../current/` 对应路径）
- [ ] 新文档已加入 `sidebars.ts` 正确分类

## 构建验证

```bash
npm run build          # 必须无错误通过
npm run serve          # 抽查几个页面：搜索、版本切换、语言切换
```

## 发布新版本（仅维护者）

```bash
npm run docusaurus docs:version <版本号>   # 如 1.2.0
```

随后在 `docusaurus.config.ts` 中：
1. `versions` 里添加新版本条目（label）
2. 将 `lastVersion` 更新为新版本号

详细步骤见站点内 [多版本管理](../docs/maintenance/version-guide)。

## 新增语言（仅维护者）

1. `docusaurus.config.ts` 的 `i18n.locales` 添加语言代码
2. `npm run write-translations -- --locale <语言>`
3. 创建 `i18n/<语言>/docusaurus-plugin-content-docs/current/` 开始翻译

详细步骤见站点内 [多语言管理](../docs/maintenance/i18n-guide)。

## 常见坑

| 坑 | 说明 |
| --- | --- |
| 链接用绝对路径 `/docs/...` | 多版本下会跳到错误版本，一律用相对路径 |
| 文件名翻译后不一致 | 翻译目录结构必须与 `docs/` 完全一致 |
| 忘记加 `sidebar_position` | 文档排序可能不符合预期 |
| 修改已发布版本却改错地方 | 已发布版本改 `versioned_docs/`，最新内容改 `docs/` |
