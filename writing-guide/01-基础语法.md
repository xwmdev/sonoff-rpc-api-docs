# 01 基础语法

> 写作参考（本地），不会渲染到站点。

## 标题

`#` 一级标题即页面大标题，一般由 front matter 的 `title` 控制；正文用 `##` 到 `####`。

```markdown
## 二级标题

### 三级标题
```

## 加粗 / 斜体 / 行内代码

```markdown
**加粗**，*斜体*，`行内代码`

重要参数是 `accessToken`，请**妥善保管**。
```

## 列表

```markdown
- 无序列表项一
- 无序列表项二

1. 第一步：打开浏览器
2. 第二步：访问站点
```

## 链接

```markdown
[站内相对链接](../api/user-auth)        <!-- 站内文档用相对路径 -->
[外部链接](https://docusaurus.io)
[锚点跳转](#标题-锚点)                   <!-- 锚点默认取标题的小写连字符 -->
```

:::tip 站内链接一律使用相对路径
例如 `docs/api/user-auth.md` 里引用同目录文档写 `./rate-limit`，引用上一级写 `../intro`。不要写绝对路径（`/docs/...`），否则多版本下会串版本。
:::
