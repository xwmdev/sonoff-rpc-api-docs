# 写作语法指南

> 本文档是**开发者本地写作参考**，仅供本项目开发者查阅，**不会被渲染到文档站点**（该目录不在 Docusaurus 的扫描范围内）。

## 这是什么

本站基于 Docusaurus，文档用 **Markdown**（.md / .mdx）编写。本指南汇总了写文档最常用的语法，按顺序读一遍即可上手。

## 文档目录

| 文件 | 内容 | 适合场景 |
| --- | --- | --- |
| [01-基础语法.md](./01-基础语法.md) | 标题、加粗、列表、链接、图片、表格、代码块 | 日常写文档必看 |
| [02-进阶组件.md](./02-进阶组件.md) | 提示框（admonition）、标签页（tabs）、流程图（mermaid）、折叠块 | 需要强调、演示、画图时 |
| [03-元数据与组织.md](./03-元数据与组织.md) | front matter、目录与侧边栏、多语言多版本写作注意 | 新开文档/目录时 |
| [04-发布检查清单.md](./04-发布检查清单.md) | 写完后、发布前要做什么 | 每次写完文档 |

## 快速上手三句话

1. 在 `docs/` 下新建 `xxx.md`，开头写 front matter（`title` / `sidebar_position`）
2. 用 Markdown 正常写正文，需要特殊效果时查本指南对应章节
3. 运行 `npm run start` 本地预览，效果满意后按 `04-发布检查清单.md` 收尾

## 写作流程

```
写新文档 → 本地预览(npm run start) → 同步英文翻译 → 提交
```
